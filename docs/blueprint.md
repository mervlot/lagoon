# **App Name**: Lagoon Lagos Cuisine

## Core Features:

- Engaging Homepage Carousel: A dynamic hero section with a rotating carousel showcasing the restaurant's ambiance, signature dishes, and special offers.
- Interactive Digital Menu: A comprehensive, multi-page menu experience with dish categories, detailed descriptions, pricing, and high-quality imagery for easy browsing.
- Seamless Table Booking: A user-friendly system allowing patrons to select a preferred date, time, and party size to reserve a table online.
- Efficient Online Ordering: A streamlined process for customers to browse menu items, add selections to a cart, and submit an order for pickup or delivery.
- Comprehensive Contact Page: A dedicated page with a contact form, direct communication details, and an interactive map showing the restaurant's location.
- AI Dish Recommender Tool: An AI tool that suggests personalized dish recommendations to users based on their specified tastes, dietary restrictions, or current mood.

## Style Guidelines:

- Primary color: A sophisticated, deep ocean blue (#2989CC), representing the 'Lagoon' concept while maintaining a modern and elegant feel. It offers excellent contrast against a lighter background.
- Background color: A very light, cool blue-grey (#E8EFF2), visually stemming from the primary hue but heavily desaturated, providing a clean, fresh, and modern canvas.
- Accent color: A vibrant aqua-green (#14E6C0), analogous to the primary but distinctly different in saturation and brightness, used for calls to action and highlighting key information, evoking freshness.
- Headline font: 'Space Grotesk' (sans-serif), for a modern, slightly techy, and distinctive look, giving character to titles and headings. Body font: 'Inter' (sans-serif), for its objective, highly readable, and clean aesthetic, suitable for all general text.
- Utilize modern, clean line-art icons that complement the contemporary visual style, avoiding overly ornate or childish designs.
- Employ a responsive, grid-based layout with generous white space to create an airy, premium, and user-friendly experience across all devices. Focus on clear visual hierarchy.
- Integrate simple, subtle animations for element entrances, hover effects on interactive components, and smooth page transitions using Framer Motion to enhance the modern and engaging feel without being distracting.
